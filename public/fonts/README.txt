Noto Sans SC (Simplified Chinese), Regular and Bold

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC
Font files are unmodified official regional-subset OpenType fonts.
License: SIL Open Font License 1.1; see OFL.txt in this directory.
Retrieved 2026-10-21 for browser-side PDF generation.

The PDF renderer embeds only the glyphs used in each exported document.
Regular is used for the Chinese italic font slot because upstream Noto Sans SC
does not distribute an italic face. Italic emphasis also uses a distinct text color.
