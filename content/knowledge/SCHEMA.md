# Authored bilingual course knowledge
Each course is a JSON file CODE.json with {courseId, overview:{zh,en}, pathway:[{resourceId,reason:{zh,en}}], materials:[...]}. Only course knowledge files (not scripts/UI) are assigned to content authors.
Material: {resourceId, overview:{zh,en}, sourceNote?:{zh,en}, groups:[{id,title:{zh,en},concepts:[{id,title:{zh,en},explanation:{zh,en},pages:number[],example?:{zh,en},confusion?:{zh,en}}]}], links:[{from:conceptId,to:conceptId,relation:{zh,en}}], questions:[{id,conceptIds:string[],prompt:{zh,en},options:[{zh,en},{zh,en},{zh,en},{zh,en}],answer:0|1|2|3,explanation:{zh,en},pages:number[]}], coverage:{coveredPages:number[],excludedPages:[{pages:number[],reason:{zh,en}}]}}
All IDs are globally unique, e.g. material-24-c1, material-24-q1, material-24-g1.
For every meaningful source concept provide bilingual substantive teaching explanation and a real source page. Organize groups per major topic preserving part-of/parallel/sequence structures. links express meaningful within-material relations with explanatory phrases. Each concept must be covered by at least one meaningful MCQ; no fixed question/knowledge limit; questions may cover multiple concepts ONLY if the actual reasoning tests all. All questions bilingual four plausible options, exactly one best answer, balanced answer positions, bilingual reason explaining correct and distractor error. Theory, differences, methods, worked examples, applications all need coverage, source-grounded.
Coverage list all substantive pages, explicitly exclude title/admin/references/repeated pages with reasons. Do not invent page citations for videos/images/zips; use [] and precise sourceNote. Original images can be cited page 1 if UI supports images (but manifest pageCount=0); prefer [] with sourceNote. If video duplicates a deck, inspect available video content/frames, mark companion summary vs audio transcript accurately. Can reuse duplicate source content only with IDs remapped to target material.
Use outputs/knowledge-source/{material-id}.txt / .json and content/material-previews.json; PDFs original or rendered preview at outputs/course-assets paths. Render key diagrams via pdftoppm and inspect with view_image. Read source end-to-end. No web supplement needed unless explicitly labeled. Chinese translations should be clear; English paraphrases match Chinese claims. Never expose student contact details from documents.
User wants every lecture plus course linkage and MCQs; source plans/assignments/guides can use practical learning objective/checklist knowledge with meaningful questions instead of made-up theory. Keep all48 resource IDs represented.

Each material also has sourceSha256 equal to the original-file sha256 in material-previews.json. A changed source must trigger review of its concepts, relationships, questions and page coverage before this digest is updated. Keep existing concept/question IDs where their meaning is unchanged; question hashes prevent stale answers from being treated as current.
